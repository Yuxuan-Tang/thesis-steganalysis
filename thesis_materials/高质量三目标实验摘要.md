## 关键实验结论

1. 步数校准：`num_steps=30` 的正确恢复 SSIM 为 0.979801，三目标评分为 0.755425；`num_steps=50` 的正确恢复 SSIM 为 0.976812，三目标评分为 0.751645。因此在本机 RTX 3050 Ti 4GB 条件下，30 步不是单纯为了省时间，而是在本实验样本上取得了更优的综合结果。

2. 核心样本：`style_dog` 的密钥安全差值最高，为 0.051517，三目标评分最高，为 0.785265；`similar_face` 的正确恢复质量最高，SSIM 为 0.979801，但语义泄露度也较高，为 0.723419。说明相似语义 Prompt 有利于恢复，但更容易暴露秘密图像的语义结构。

3. `noise_flip_scale` 参数：从 0.03 增至 0.08 时，密钥安全差值从 0.019153 提升到 0.039507，三目标评分从 0.745945 提升到 0.776692。本文可推荐 `noise_flip_scale=0.08` 作为更偏安全性的配置，同时说明其 stego SSIM 从 0.956050 下降到 0.931315，存在可见差异增强的代价。

4. `edit_strength` 参数：从 0.5 增至 0.7 时，语义泄露度从 0.737016 降至 0.703508，三目标评分从 0.751799 提升到 0.758096；但 stego SSIM 从 0.955204 降至 0.923556。说明增大编辑强度可降低秘密图像结构泄露，但会削弱载密图像与秘密图像之间的视觉相似性。

5. Prompt 对比：无关场景 Prompt 的三目标评分最高，为 0.782245，密钥安全差值为 0.049763，语义泄露度最低，为 0.705699；相似人脸 Prompt 的三目标评分最低，为 0.755425，语义泄露度最高，为 0.723419。该结果能支撑论文提出“Prompt 语义距离影响隐蔽性”的观点。

## 推荐写法

论文中可把方法命名为“面向抗隐写分析的轻量化三目标参数选择策略”。评价准则如下：

- 正确恢复质量越高越好，使用正确恢复图与秘密图像的 PSNR、SSIM、MAE、RMSE 衡量；
- 错误密钥恢复质量越低越好，使用 `correct_recover_ssim - wrong_recover_ssim` 表示密钥安全差值；
- 语义泄露度越低越好，使用秘密图像与载密生成图像的 SSIM 和边缘相似度加权衡量；
- 综合评分定义为 `correct_ssim + key_security_gap - 0.35 * semantic_leakage`，用于在恢复质量、安全性和隐蔽性之间选择折中参数。

## 论文中建议采用的推荐配置

若论文强调“抗恢复攻击能力”，推荐配置：

- `num_steps=30`
- `noise_flip_scale=0.08`
- `edit_strength=0.6`
- Prompt 尽量避免与秘密图像过度相似

若论文强调“恢复质量与图像自然性平衡”，推荐配置：

- `num_steps=30`
- `noise_flip_scale=0.05`
- `edit_strength=0.6`
- 使用风格化或弱相关 Prompt

最终正文建议写成：本文实验表明，扩散无载体隐写的安全性不仅取决于密钥扰动机制，也受到 Prompt 语义选择和编辑强度影响。相似 Prompt 可提升恢复稳定性，但会增加语义泄露风险；较大的 Noise Flip 强度能增强错误密钥区分度，但可能降低载密图像与秘密图像之间的相似性。因此，本文提出的三目标评估流程能够为低算力环境下的扩散无载体隐写参数选择提供依据。
