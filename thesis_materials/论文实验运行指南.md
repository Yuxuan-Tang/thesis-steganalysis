# DiffStega 低算力论文实验运行指南

## 1. 环境与空间策略

本项目所有代码、环境、缓存和输出都放在 `D:\thesis`，避免占用 C 盘。运行 PowerShell 脚本前建议在项目根目录执行：

```powershell
cd D:\thesis
```

缓存目录固定为：

- `D:\thesis\.cache\huggingface`
- `D:\thesis\.cache\torch`
- `D:\thesis\.cache\pip`
- `D:\thesis\.cache\conda_pkgs`

## 2. 安装环境

```powershell
.\setup_diffstega_env.ps1
```

该脚本会创建 `D:\thesis\envs\diffstega`，并安装 DiffStega 与分析脚本需要的依赖。这里将 `huggingface_hub` 锁定为 `0.20.2`，用于兼容 `diffusers==0.26.3`。

## 3. 下载 DiffStega 必需模型

可直接运行：

```powershell
conda run -p D:\thesis\envs\diffstega python D:\thesis\tools\download_ip_adapter_models.py
```

脚本会按 DiffStega README，将以下文件放入 `D:\thesis\DiffStega\pretrained_models`：

- `ip-adapter-plus_sd15.bin`
- `ip-adapter-plus-face_sd15.bin`
- `image_encoder_for_ip_adapter\pytorch_model.bin`
- `image_encoder_for_ip_adapter\config.json`

不要下载 UniStega 全量数据集，低算力救急路线不需要。

## 4. 运行低显存 DiffStega 示例

```powershell
.\run_diffstega_low_vram.ps1
```

脚本默认使用：

- `--single_model`
- `--optional_control none`
- `--num_steps 10`
- `--low_vram`

这些设置是为了适配 RTX 3050 Ti 4GB。若显存仍不足，优先只保留第一组 style prompt。

## 5. 运行 LSB 对照与统计分析

```powershell
.\run_analysis.ps1
```

输出位置：

- `experiments\lsb_outputs`：传统 LSB 对照结果；
- `experiments\analysis\metrics.csv`：PSNR、SSIM、MAE、RMSE；
- `experiments\analysis\*_comparison.png`：论文对比图；
- `experiments\analysis\*_hist.png`：灰度直方图；
- `experiments\analysis\*_residual.png`：噪声/边缘残差图。

## 6. 论文写法提示

本实验不要写成“提出全新隐写算法”。更稳妥的表述是：

> 本文基于公开的 DiffStega 扩散无载体隐写框架，设计了一套轻量化安全评估流程，从恢复质量、错误密钥恢复、统计残差和传统 LSB 对照角度分析其抗隐写分析特性。

“面向抗隐写分析”主要体现在：

- 无载体生成机制没有传统 cover-stego 修改对；
- 正确密钥与错误密钥恢复结果差异明显；
- 与 LSB 修改式隐写相比，DiffStega 的安全性讨论重点从“像素修改痕迹”转向“密钥依赖恢复”和“生成图像自然性”。
